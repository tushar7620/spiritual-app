Spiritual App Preview

Open index.html with VS Code Live Server.

Gita page:
- Text-only Bhagavad Gita reader
- 18 chapters / 700 verses
- Sanskrit shloka + Hindi meaning
- Search
- Book-style page flip animation
- One navigation sliding indicator
- No PDF or book viewer
- No Mala history on Gita page

The Gita text is loaded from the public GitHub JSON corpus at runtime.
Internet access is required for the complete corpus.
